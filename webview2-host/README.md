# Akiri Browser — WebView2 хост (этапы 1–2)

Переезд с Electron на **настоящий Chromium** (WebView2, движок Edge 151 —
тот же, что у твоего Chrome). Решает главную проблему: Google принимает вход
(«Этот браузер или приложение может быть небезопасным» больше не появляется —
это доказано прототипом `poc-webview2/`).

## Что уже работает

### Этап 2 (вкладки · сессия · адресная строка)

- **Порядок вкладок после перетаскивания сохраняется** — сессия пишется
  в порядке UI (host получает `reorder-tabs` от app.js, гард для Electron).
- **Индикатор звука в вкладке** — `IsDocumentPlayingAudioChanged` → UI
  получает `audible`-состояние (проверено с реально играющим видео).
- **Сессия сохраняется при создании вкладки** — ничего не теряется при
  неожиданном закрытии (раньше сохранялась только по debounce-таймеру).
- **Подсказки адресной строки** — история + закладки + поиск, как у Electron.

## Что уже работает (этап 1)

- **Главное окно** — тёмный фрейм, заголовок от активной вкладки.
- **UI браузера** — тот же `renderer/index.html` + `app.js` + `styles.css`
  (вкладки, адресная строка, кнопки, закладки, история, меню ☰, AI-панель).
- **Вкладки** — создание/закрытие/переключение/перетаскивание, сессия
  восстанавливается при запуске (те же `session.json`, как у Electron).
- **Навигация** — адресная строка, назад/вперёд/обновить/стоп, Ctrl+L/T/W,
  Alt+←/→, Ctrl+Tab, Ctrl+D (закладка), Ctrl+J (загрузки), Ctrl+H (история).
- **Собственные страницы** — NTP (новая вкладка), настройки, история,
  загрузки, пароли, «о браузере» — через виртуальный хост `https://akiri.local/`.
- **Данные совместимы с Electron-версией** — те же JSON в
  `%APPDATA%\Akiri Browser` (settings/bookmarks/history/session/downloads).
- **Загрузки** — файлы в «Загрузки», прогресс и скорость видны в панели загрузок.
- **Контекстные меню** — страницы (назад/вперёд/обновить, копировать,
  поиск выделенного, открыть ссылку) и вкладки (дублировать/закрепить/закрыть).
- **Полноэкранный режим** — по кнопке в меню и по видео (requestFullscreen).
- **Скриншот страницы** — сохраняется в «Загрузки».

## Ещё НЕ сделано (следующие этапы)

- AI-ассистент (мост и UI готовы, хост-метод вернёт «появится в следующем этапе»).
- Менеджер паролей, поиск по странице (Ctrl+F), режим чтения, ночной режим.
- Инкогнито-окна, новое окно (Ctrl+N), обновления браузера, меню «Файл/Правка/Вид».
- Chrome-расширения (в WebView2 их нет — как и у нас в Electron; свои «расширения» не портированы).
- UA: сейчас как у Edge (`Edg/151...`) — Google это принимает, но для вида
  «своего браузера» можно убрать Edg/ через `--user-agent` (следующий этап).

## Сборка и запуск (без dotnet SDK)

```
build.bat        → AkiriBrowser.exe + WebView2Loader.dll
run.bat          → сборка + запуск
```

Для отладки (CDP-порт открывает DevTools-протокол):

```
set AKIRI_CDP_PORT=9227
AkiriBrowser.exe
→ http://127.0.0.1:9227 (json/version, targets, Runtime.evaluate и т.д.)
```

## Как это устроено

- **UI** грузится в WebView2 на всё окно через `SetVirtualHostNameToFolderMapping`
  (`https://akiri.local/` → папка `../renderer`). Содержимое рендерера
  не меняется: `renderer/webview-bridge.js` определяет `window.browserAPI`
  поверх `chrome.webview.postMessage`, когда preload Electron отсутствует.
- **Вкладка** — отдельный WebView2 (как WebContentsView), позиционируется
  по прямоугольнику `#views`, который UI шлёт через `setViewRect`.
- **Мост** — тот же набор методов, что `preload.js` у Electron
  (create-tab, navigate-tab, tab-state, set-view-rect, load-settings, …).
- **WebView2 Runtime** — 151.0.4129 (уже установлен на машине; при отсутствии
  реестровой записи хост сам находит папку EdgeWebView\Application).

## Проверка

```
node tools/login-test.js 9227   (после запуска с AKIRI_CDP_PORT=9227)
```

Google отвечает «Не удалось найти этот аккаунт» (нормальный ответ), а не
«браузер небезопасен» — риск-проверка пройдена, потому что TLS/отпечаток
настоящего Chromium.
