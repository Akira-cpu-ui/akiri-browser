# Akiri Browser — прототип на WebView2 (настоящий Chromium)

**Цель эксперимента:** проверить, что переезд с Electron на WebView2 (движок Edge =
настоящий Chromium) решает проблему входа в Google («Этот браузер или приложение
может быть небезопасным»).

## Результат — ГИПОТЕЗА ПОДТВЕРЖДЕНА ✅

Один и тот же тест входа Google (форма → ввод email → Next) на этой машине:

| Движок | Результат |
|---|---|
| Electron (наш браузер 0.17.x) | `/v3/signin/rejected` — «браузер или приложение небезопасны» |
| Chrome 151 (настоящий) | «Не удалось найти этот аккаунт» — **проходит** |
| Edge 151 (настоящий) | «Не удалось найти этот аккаунт» — **проходит** |
| **WebView2 151 (встроенный)** | **«Не удалось найти этот аккаунт» — ПРОХОДИТ** |

Вывод: Google отличает встроенные браузеры по отпечатку самого бинарника
(TLS/транспорт), а не по заголовкам/JS. Мы сделали HTTP- и JS-отпечаток нашего
браузера идентичным Chrome — не помогло. WebView2 — это тот же настоящий Chromium
(151.0.4129, тот же, что у Edge), поэтому Google его принимает сразу.

## Что здесь лежит

- `Poc.cs` — минимальный хост: WinForms-окно с WebView2, открывает `AKIRI_POC_URL`.
- `build.bat` — сборка без dotnet SDK (через csc.exe из .NET Framework, C# 5).
- `libs/` — WebView2 1.0.4129.50 (Core/WinForms/Loader) из NuGet.
- `AkiriPoc.exe` — собранный прототип.

## Как собрать и запустить

```
build.bat
set WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--remote-debugging-port=9227
set AKIRI_POC_URL=https://accounts.google.com/
AkiriPoc.exe
```

CDP-порт 9227 открыт — можно гонять тесты (`node tools/login-test.js 9227`).

## План миграции на WebView2 (реалистичный)

Архитектура переносится 1-в-1 с текущей (Electron): UI — HTML (наш index.html уже
готов), каждая вкладка — отдельный WebView2, хост — C# (WinForms).

1. **Хост-каркас (C#)**: главное окно, UI-WebView2 (наши index.html/app.js),
   N WebView2 для вкладок — по аналогии с WebContentsView.
2. **Мост UI↔хост**: postMessage/WebMessageReceived вместо IPC
   (`browserAPI` → шайба-мост в index.html, хост отвечает).
3. **Логика из main.js на C#**: вкладки, сессия (restoreSession), закладки,
   история, загрузки, пароли, обновления, AI-чат, инкогнито — всё это
   переносится как есть (те же JSON-файлы данных — совместимы!).
4. **Страницы настроек/истории/загрузок/паролей** — работают без изменений
   (они уже file:// + pageAPI; заменить pageAPI на мост).
5. **Плюсы WebView2**: настоящий Chromium (вход в Google работает, совместимость
   сайтов 100%), движок обновляется Microsoft'ом (EdgeUpdate), автодоставка.
6. **Минусы**: Chrome-расширения не поддерживаются (как и в Electron по сути —
   у нас свои «расширения»); C#-хост вместо JS.

Оценка: при фокусной работе — 2–4 недели поэтапно, каждый этап проверяем
отдельно (вкладки → навигация → сессия → данные → AI → обновления). Electron
остаётся рабочим, пока миграция идёт.
