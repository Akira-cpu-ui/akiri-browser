# Сайт и обновления (GitHub Pages)

Эта папка публикуется GitHub Pages и отдаётся по адресу:

```
https://<user>.github.io/akiri-browser/
```

## Что здесь

- `index.html` — лендинг браузера (кнопка «Скачать», «Что нового»).
- `version.json` — файл версий: браузер опрашивает его и сам скачивает
  новый установщик в фоне, ставит при закрытии.

Адрес файла версий для браузера:

```
https://<user>.github.io/akiri-browser/version.json
```

## Как выходит новая версия

Автоматически, одной командой:

```bash
node tools/publish-update.js 0.18.0 --notes="что нового"
```

Скрипт:
1. собирает установщик (`npm run dist`);
2. заливает его в **GitHub Release** (тег `v0.18.0`);
3. обновляет `version.json` и лендинг в этой папке;
4. коммитит и пушит — Pages обновляются сами, за 1–2 минуты.

Дальше у всех, у кого установлен Akiri Browser, обновление появится
автоматически: браузер заметит новую версию, скачает в фоне и поставит
при закрытии.
