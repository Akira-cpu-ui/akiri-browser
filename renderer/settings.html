Расширения

Расширения загружаются из папки с распакованным расширением (папка, где лежит manifest.json). Прямая установка из Chrome Web Store (CRX) в Electron невозможна — скачайте расширение и распакуйте его, либо возьмите папку из %LOCALAPPDATA%\Google\Chrome\User Data\Default\Extensions\… (включите «Режим разработчика» в Chrome → «Загрузить распакованное» не нужно — просто найдите папку версии расширения).

Обновления

Браузер проверяет файл версий (JSON) по этому адресу при запуске и каждые 6 часов. Формат файла: {"version": "0.12.0", "url": "https://…/setup.exe", "notes": "что нового"}. Когда выйдет новая сборка, обновите этот файл — и всем установленным копиям браузера придёт уведомление «Доступна новая версия». Кнопка «Установить обновление» на странице «О браузере» (☰ → О браузере) скачивает установщик, закрывает браузер, обновляет и открывает новую версию сам.

Данные

Все данные хранятся в обычных файлах JSON в папке приложения: закладки — bookmarks.json, история — history.json, сессия — session.json, настройки — settings.json, пароли (зашифрованы) — passwords.json.
